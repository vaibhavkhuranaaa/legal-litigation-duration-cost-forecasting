# Interface contract

The local interface has two task-focused workspaces backed by the versioned API.

## Portfolio

The portfolio view reports governed aggregate workload, pending inventory, case-identity coverage, and reviewed RECAP match availability. Its cohort chart is an observed administrative-termination benchmark through the disclosed development cutoff, not a duration forecast.

## Matter planner

The planner refuses predicted completion dates and directs users to observed cohort context. Its low, base, and high staffing and budget outputs are deterministic sensitivity calculations from user-entered assumptions. They use no observed cost data and are not real cost forecasts.

## Shared boundaries

- Capability readiness remains visible in both workspaces.
- Observed, synthetic, unavailable, and refusal states have explicit text and color treatment.
- Data export includes only the aggregate API responses already shown in the interface.
- Loading, connection error, retry, empty, and result states are present.
- Keyboard focus, labels, landmarks, reduced-motion handling, and responsive layouts are part of the release contract.

The product is an operations planning instrument, not legal advice.
